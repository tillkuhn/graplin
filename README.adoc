= 🍇 Graplin

A ridiculously lightweight Go client for pushing metrics to Grafana Cloud using https://docs.influxdata.com/influxdb/cloud/reference/syntax/line-protocol/[InfluxDB Line Protocol] over the public
https://grafana.com/docs/grafana-cloud/send-data/metrics/metrics-influxdb/push-from-telegraf/#pushing-from-applications-directly%5BPush[HTTP Ingestion Endpoint].

== What's this all about?

Ever wanted to push metrics to Grafana Cloud without installing separate components importing half of GitHub? Graplin is your answer. It's a tiny, dependency-free Go client that speaks InfluxDB Line Protocol to Grafana's push endpoint.

Think of it as the minimalist's metric delivery service - no bloat, no fuss, just pure Go goodness.

== Why Graplin?

* **Zero dependencies** - Uses only standard Go packages
* **Lightweight** - Less than 200 lines of code
* **Simple API** - Configure once, push forever
* **Battle-tested** - Handles errors like a champ
* **Grafana Cloud native** - Works seamlessly with Grafana's push endpoint

== Quick Start

[source,go]
----
package main

import (
    "context"
    "time"
    "github.com/tillkuhn/graplin/pkg/graplin"
)

func main() {
    // Create a client (configure once)
    client := graplin.NewClient(
        graplin.WithHost("https://your-grafana-endpoint.grafana.net"),
        graplin.WithAuth("your-user:your-token"),
        graplin.WithDebug(true), // Optional: see what's happening
    )

    // Create a measurement
    measurement := graplin.Measurement{
        Measurement: "coffee_consumed",
        Tags: map[string]string{
            "user":   "alice",
            "type":   "espresso",
        },
        Fields: map[string]interface{}{
            "cups":    3,
            "happiness": 0.95,
        },
        Timestamp: time.Now(),
    }

    // Push it to Grafana Cloud
    err := client.Push(context.Background(), measurement)
    if err != nil {
        panic(err)
    }
}
----

== Configuration Options

* `WithHost(host string)` - Set your Grafana Cloud endpoint
* `WithAuth(auth string)` - Set credentials (format: "user:token")
* `WithDebug(debug bool)` - Enable debug logging
* `WithTimeout(timeout time.Duration)` - Set custom HTTP timeout

== What's in a Measurement?

A `Measurement` is just a fancy name for your metric data:

* **Measurement** - The name of your metric (required)
* **Tags** - Key-value pairs for filtering and grouping (optional)
* **Fields** - The actual values you're measuring (at least one required)
* **Timestamp** - When this measurement happened (optional, uses current time if not set)

== The Line Protocol Magic

Under the hood, Graplin converts your measurements to InfluxDB Line Protocol format:

```
coffee_consumed,user=alice,type=espresso cups=3i,happiness=0.95 1704067200000000000
```

But don't worry about the format - Graplin handles all the nitty-gritty details for you.

== Example

Check out the `examples/` directory for a complete working example that demonstrates how to:

* Create a Graplin client with configuration
* Generate random coffee consumption data
* Push metrics every 15 seconds
* Handle graceful shutdown with Ctrl+C

```bash
cd examples
go run .
```

The example will continuously push random coffee data (1-5 cups, 0-10 happiness score) to your Grafana Cloud endpoint until you interrupt it.

== Requirements

* Go 1.24 or later
* A Grafana Cloud account with push endpoint access
* That's it. Seriously.

Alternatively, you can push metrics directly using curl:
----
curl -iX POST https://prometheus-prod-<no>-<region>.grafana.net/api/v1/push/influx/write \
  -u "<cloud-instance-i>:<token>" \
  -H "Content-Type: text/plain"   \
  -d 'heating_metric,room=kitchen,source=grafana_cloud_docs temperature=42.0'
----
